# bgipotential.github.io

Project website and visual materials for the [BGIpotential](https://github.com/omidemam/bgipotential.git) research project, and the manuscript *Ranking the aggregate potential for blue-green infrastructure in U.S. cities*.

This repository hosts the public website for the project. For the full research codebase, data, and methodology, see the main repository:

[https://github.com/omidemam/bgipotential](https://github.com/omidemam/bgipotential.git)

## Website
